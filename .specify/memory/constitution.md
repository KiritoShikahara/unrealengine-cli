# unreal-cli Constitution

## Core Principles

### I. 独立性
unreal-cli は単独で成立する。他のリポジトリ(unity-cli、ue-cli など)のコード、パッケージ、成果物、設定を参照・コピー・依存してはならない。

### II. CLI ファーストと機械可読な出力
すべての機能は CLI コマンドとして公開する。出力はテキストと共通 JSON エンベロープの両方に対応し、終了コードで失敗の種類を区別する。失敗には必ずエラーコードと次の手順を付ける。

### III. テストファースト(例外なし)
TDD を必須とする。テストを書き、失敗を確認してから実装する。公開ツールはすべて少なくとも 1 本の自動テストを持つ。

### IV. 契約と統合テスト
CLI とエディタプラグインの間のプロトコル、ツールスキーマ、スキル契約は契約テストで守る。契約を変えるときはプロトコルバージョンを上げる。

### V. 安全と可逆性
通信はループバックに限る。変更を伴うコマンドは `--dry-run` に対応し、エディタ上の変更は Undo 単位で記録する。プロジェクトを変更する前に変更内容を表示する。

### VI. シンプルさ
依頼された範囲だけを実装する。専用ツールは頻度の高い操作に限り、それ以外は汎用プロパティ操作と Python 実行で対応する。

## 品質ゲート

- `cargo fmt --all -- --check`
- `cargo clippy --all-targets -- -D warnings`
- `cargo test --all-targets`
- `unreal-cli skills lint --severity error`
- エディタ E2E(Windows、UE 5.5〜5.8)はリリース前に必須

## Governance

この憲章は他の開発慣習より優先する。改訂には理由と移行方針の記録が必要。
